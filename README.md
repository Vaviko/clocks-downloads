# Vaviko Clocks downloads

Installers for the Vaviko Clocks desktop app. No code lives here.

- **Windows:** [Vaviko-Clocks-Setup.exe](https://github.com/Vaviko/clocks-downloads/releases/latest/download/Vaviko-Clocks-Setup.exe)
- **Mac:** [Vaviko-Clocks-Mac.dmg](https://github.com/Vaviko/clocks-downloads/releases/latest/download/Vaviko-Clocks-Mac.dmg)

After installing, open the app and connect it with the code from Clocks → Get the app on vaviko.com.
